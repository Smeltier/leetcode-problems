# LeetCode Problems (C++)

My solutions to LeetCode problems in C++, with time and space complexity notes.

## Repository structure

- `solutions/` — solutions organized by LeetCode problem number (one file per problem)

## File naming convention

I name files using:

`<problem_number>.cpp`

Examples:
- `0209.cpp`
- `0560.cpp`

## What you will find in each file

Each solution file typically includes:
- Problem name and link
- Short explanation / approach
- Time complexity
- Space complexity
- The `Solution` class (as submitted on LeetCode)

## Notes

- Runtime shown by LeetCode can vary between submissions (0 ms vs a few ms) due to measurement granularity and server variance.
